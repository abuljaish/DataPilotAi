# 🚀 DataPilot
[Website Link](https://datapilotai-1.onrender.com/)


> **Ask your data. Get answers. Discover insights.**

DataPilot is an AI-powered data analysis application that lets you interact with your datasets using natural language.

Upload your data and ask questions like:

* Who has the highest salary?
* Who is the oldest employee?
* Show employees with a salary above 90,000.
* Compare the average salary of Engineering and Marketing.
* Create a bar chart showing salary by employee.

DataPilot analyzes your dataset and returns meaningful answers, filtered results, comparisons, and visualizations.

---

## ✨ Features

### 💬 AI Query Engine

Ask questions about your dataset in natural language.

DataPilot can:

* 🔍 Filter and find records
* 📊 Calculate metrics and aggregations
* ⚖️ Compare categories and values
* 📈 Generate charts from natural language
* 🧮 Calculate averages, totals, minimums, and maximums
* 🏆 Identify top and bottom performers
* 🧠 Answer multiple questions in a single query

### 🧠 Intelligent Responses

DataPilot is designed to answer questions like an AI data analyst.

Instead of returning raw technical results:

> `MAX(age) = 38`

DataPilot provides a meaningful answer:

> **Karan Malhotra is the oldest employee at 38 years old.**

Instead of:

> `Filter returned 2 rows`

DataPilot returns the actual matching records.

### 📊 AI-Powered Chart Generation

Generate visualizations using natural language.

Example:

```text
Create a bar chart showing salary by employee.
```

DataPilot can generate charts for:

* Bar charts
* Line charts
* Pie charts
* Category comparisons
* Trends
* Distributions

Value labels are displayed on bars to make small values easier to identify.

### ⚖️ Smart Comparisons

Ask DataPilot to compare multiple groups.

Example:

```text
Compare the average salary of Engineering and Marketing.
```

DataPilot can return:

* Engineering: ₹81,666.67
* Marketing: ₹69,500
* Difference: ₹12,166.67

## 🎯 Project Goal

DataPilot aims to make data analysis accessible to everyone.

Instead of manually writing:

* SQL queries
* DataFrame operations
* Filters
* Aggregations
* Chart configurations

Users can simply **ask questions about their data**.

The goal is to make interacting with data feel as natural as having a conversation with an intelligent data analyst.
